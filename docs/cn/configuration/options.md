# 导读

原先集中在本页的配置细项已按查阅任务拆开。本页不再登记功能，也不再重复各键的默认值或端点。

- 监听、TLS、发现、健康检查、日志、管理端、终端界面、Home 和插件加载：见运行与管理各页，入口为 [监听与进程](/cn/operations/server) 与 [管理 API v8](/cn/management/apiv8)。
- 客户端调用见 [客户端密钥](/cn/api/access)。
- 账号、上游和存储见账号与上游各页，以及 [凭证目录](/cn/configuration/auth-dir)。
- 路由与请求见 [路由策略](/cn/routing/strategy)。
- 模型思考见 [模型思考能力](/cn/configuration/thinking-models)。
- `/v0/management` 已停止维护，见 [管理 API](/cn/management/api)。
