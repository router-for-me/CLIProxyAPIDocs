# 桌面客户端

项目地址：[EasyCLIProxyAPI](https://github.com/router-for-me/EasyCLIProxyAPI)
EasyCLIProxyAPI是CLIProxyAPI官方推出的桌面客户端，主要面向本地部署使用的用户。

## 功能介绍
EasyCLIProxyAPI可以将多个Codex、Antigratity、Grok、Claude等的账号订阅额度反代成API格式，供任意工具使用，实现token free(自由)。同时也支持多个API聚合接入，方便用户接入多个渠道使用。此外还提供了智能体配置功能，便于用户一键配置codex、claude code、pi、opencode、openclaw等智能体。
