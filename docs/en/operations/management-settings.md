# Management settings

## 1. What this solves

Decide whether the management API is open to non-local callers, which key authenticates it, where the control panel is downloaded from, and which management address the terminal interface uses when it is a client.

## 2. Scope and non-goals

These keys belong to `management`. They do not describe every `/v8/management` route. The routes are in [Management API v8](/management/apiv8). `/v0/management` is no longer maintained. See [Management API](/management/api). Home mode does not expose the management API.

## 3. How to configure or call it

```yaml
management:
  allow-remote: false
  secret-key: ""
  disable-control-panel: false
  panel-github-repository: "https://github.com/router-for-me/Cli-Proxy-API-Management-Center"
```

The sample also comments out these two. When they are not written, section 4 defaults apply:

```yaml
management:
  # disable-auto-update-panel: false
  # base-url: "https://example.invalid"
```

Use the placeholder `YOUR_API_KEY` for the key. Plaintext is bcrypt-hashed on load and written back into the configuration. Requests still send the plaintext.

When calling the management API, including a request from localhost, send the key in either of these ways:

- `Authorization: Bearer YOUR_API_KEY`
- `X-Management-Key: YOUR_API_KEY`

If `Authorization` is not `Bearer` plus the key, the whole header value is treated as the key.

## 4. Details

The Default column matches the ledger `defaults` verbatim.

| Field | Meaning | Default | Constraint |
| --- | --- | --- | --- |
| management.allow-remote | Whether non-localhost access to the management API is allowed. | false | When false, a non-local caller receives 403 with the error `remote management disabled`. A local caller still needs the key. A non-empty `MANAGEMENT_PASSWORD` environment variable forces remote access, and that value exists only in memory. |
| management.base-url | Remote management API base URL used by TUI client mode. | empty string | The command-line `--management-base-url` wins. If both are empty, `http://127.0.0.1:` plus the port is used. The port is a positive `server.port`, otherwise 8317. |
| management.disable-auto-update-panel | Whether to turn off the periodic background update of management-panel assets. | When false (the default), the background updater remains enabled; when true, the panel is only downloaded on first access if missing. | When true, it is downloaded only on first access if it is missing locally, and it is not updated automatically after that. |
| management.disable-control-panel | When true, the built-in management UI is neither served nor synced. | false | It does not change whether the management API routes themselves are registered. |
| management.panel-github-repository | GitHub repository from which management-panel assets are fetched. | empty string | A repository URL or a releases API address is accepted. If it is empty on load, `https://github.com/router-for-me/Cli-Proxy-API-Management-Center` is filled in. |
| management.secret-key | Management key. It may be plaintext or a bcrypt hash. | empty string | Plaintext is hashed and written back on load or save. When this, `MANAGEMENT_PASSWORD`, and the local password from startup are all empty, management routes are not registered, and `/v0/management` and `/v8/management` return 404. |

## 5. Common errors and limits

After 5 consecutive authentication failures from the same client IP, including localhost, that client is banned for about 30 minutes with status 403. A missing key is 401 `missing management key`. A wrong key is 401 `invalid management key`. Home mode is always 404, even if a key is set. The local password from `--password`, or generated by TUI standalone mode, accepts only requests from `127.0.0.1` or `::1` and is not written into the configuration.

## 6. Related behavior

The terminal client is in [Terminal interface](/operations/tui). Configuration reads and writes are in [Management API v8](/management/apiv8). The panel page remains [Web UI](/management/webui).
