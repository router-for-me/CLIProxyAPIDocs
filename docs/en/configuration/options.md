# Guide

Configuration details that used to be gathered on this page have been split by lookup task. This page no longer registers features, and it no longer repeats each key's default or endpoints.

- Listening, TLS, discovery, health checks, logs, the management endpoint, the terminal interface, Home, and plugin loading: see the operations and management pages. The entries are [Listener and process](/operations/server) and [Management API v8](/management/apiv8).
- Client calls are in [Client API keys](/api/access).
- Accounts, upstreams, and storage are on the account and upstream pages, and in [Authentication directory](/configuration/auth-dir).
- Routing and requests are in [Routing strategy](/routing/strategy).
- Model thinking is in [Model thinking](/configuration/thinking-models).
- `/v0/management` is no longer maintained. See [Management API](/management/api).
