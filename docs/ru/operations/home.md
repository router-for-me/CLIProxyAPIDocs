# CLIProxyAPI Home

## 1. Какую задачу решает этот раздел

Подключает этот процесс к CLIProxyAPI Home с помощью JWT плоскости управления: получает сертификат mTLS, забирает конфигурацию из Home и работает с этой конфигурацией. Обнаружение узлов кластера можно отключить, чтобы адрес из JWT оставался фиксированным.

## 2. Когда применимо и чего здесь нет

Это не API управления и не терминальный интерфейс. После включения Home маршруты `/v0/management` и `/v8/management` возвращают 404. Локальные Postgres, объектное хранилище и хранилище Git выключаются, пока конфигурация загружается из Home. Успех синхронизации плагина с Home здесь не раскладывается на шаги установки. Каталог плагинов описан в разделе [Загрузка плагинов и магазин](/ru/operations/plugins).

## 3. Как настроить или вызвать

```bash
cli-proxy-api --home-jwt YOUR_API_KEY
```

JWT уже должен содержать поля, которые требует плоскость управления. Не записывайте настоящий JWT в файл конфигурации или в документацию.

Оставить адрес из JWT и не выполнять обнаружение CLUSTER NODES:

```bash
cli-proxy-api --home-jwt YOUR_API_KEY --home-disable-cluster-discovery
```

Если `--home-jwt` в командной строке пуст, непустая переменная окружения `HOME_JWT` или `home_jwt` заполняет то же значение.

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| --home-disable-cluster-discovery | Выключает обнаружение CLUSTER NODES в Home и продолжает использовать адрес из `--home-jwt`. | false | `DisableClusterDiscovery` становится true только после того, как JWT разобран и создана конфигурация Home. |
| --home-jwt | JWT плоскости управления Home для получения сертификата mTLS и соединения. | empty string | Из него должны разбираться `certificate_id`, `cluster_id`, `ca_fingerprint`, `enrollment_secret`, а также непустой IP и положительный порт. Если он недействителен, записывается `invalid -home-jwt` и запуск завершается. Неудачная загрузка конфигурации тоже останавливает запуск. |
| CLIProxyAPI Home | Подключается к CLIProxyAPI Home с помощью JWT плоскости управления. |  | После успеха конфигурация читается из Home, статистика использования устанавливается в true, а порт при пропуске или неположительном значении нормализуется к 8317. |

## 5. Типичные ошибки и границы

Если JWT состоит не из трёх частей, не хватает одного из полей выше или целевой адрес недействителен, прокси не запускается. Ошибка получения или разбора конфигурации из Home тоже возвращает управление. Неудачная синхронизация плагина записывает ошибку и останавливает дальнейший запуск. В режиме Home не рассчитывайте на локальный API управления. Вызовы получают 404.
