# Keep-alive до первого токена

## 1. Какую задачу решает этот раздел

Некоторые клиенты разрывают соединение из-за простоя до прихода первого токена. Этот переключатель позволяет отправлять сердцебиения SSE в этот промежуток.

## 2. Когда применимо и чего здесь нет

Он управляет только временем до первого токена. Интервал по-прежнему задаёт `keepalive-seconds`. Если этот ключ true, а интервал не положителен, ничего не отправляется. Сама конфигурация интервала Ping WebSocket не меняется.

## 3. Как настроить или вызвать

```yaml
requests:
  streaming:
    keepalive-seconds: 0
    send-keepalive-before-ft: false
```

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| requests.streaming.send-keepalive-before-ft | Отправлять ли сердцебиения SSE до первого токена. | Default is false. | Сердцебиение отправляется только когда этот ключ true и keepalive-seconds больше 0. Один true не включает keep-alive. |

## 5. Типичные ошибки и границы

false ошибкой не является. true вместе с `keepalive-seconds` равным 0 или отрицательным тоже не отправляет сердцебиение. Сама конфигурация не отклоняется.
