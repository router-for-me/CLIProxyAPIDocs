# Повтор до первого байта

## 1. Какую задачу решает этот раздел

Если потоковый ответ не удаётся до того, как клиенту записан хотя бы один байт, прокси ещё может сменить учётные данные или переждать временную ошибку. Этот ключ ограничивает число таких безопасных повторов.

## 2. Когда применимо и чего здесь нет

Это происходит только до отправки первого байта. После того как байт записан клиенту, этот ключ для повтора не используется. Это также не круг учётных данных `routing.retry.request-retry`.

## 3. Как настроить или вызвать

```yaml
requests:
  streaming:
    bootstrap-retries: 0
```

В примере конфигурации при включении записано 1. Нулевое значение, когда поле не записано, — это defaults в таблице.

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| requests.streaming.bootstrap-retries | Число потоковых повторов, допустимых до отправки первого байта. | Default is 0. | Меньше или равно 0 выключает. Отрицательное значение считается 0. Используется для смены учётных данных или восстановления после временной ошибки до записи байта. |

## 5. Типичные ошибки и границы

0 или отрицательное значение не отклоняется и не становится одним повтором. После отправки первого байта это число больше не используется.
