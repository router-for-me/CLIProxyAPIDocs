# Охлаждение

## 1. Какую задачу решает этот раздел

После сбоя upstream прокси может временно убрать учётные данные или модель из выбора. Здесь задаётся, планируется ли такое охлаждение, записывается ли состояние охлаждения на диск и как долго охлаждается временная ошибка upstream.

## 2. Когда применимо и чего здесь нет

Это глобальная политика охлаждения. Если `disable-cooling` есть на учётных данных или провайдере, побеждает это явное значение, включая явный false. Экспоненциальная задержка после исчерпания квоты здесь не задаётся, проект или модель предпросмотра не переключаются. Режим Home не планирует локальное охлаждение в этом процессе.

## 3. Как настроить или вызвать

```yaml
routing:
  cooldown:
    disable-cooling: false
    save-cooldown-status: false
    transient-error-cooldown-seconds: 0
```

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| routing.cooldown.disable-cooling | При true охлаждение учётных данных и модели не планируется. | false | Явное значение на учётных данных или провайдере его перекрывает. Режим Home не планирует локальное охлаждение. |
| routing.cooldown.save-cooldown-status | Записывать ли состояние охлаждения во время работы рядом с учётными данными. | false | При true рядом с каждыми учётными данными пишется файл .cds. При false оно остаётся только в памяти. |
| routing.cooldown.transient-error-cooldown-seconds | Секунды охлаждения временной ошибки upstream. | 0 keeps the legacy default cooldown. | Применяется к 408, 500, 502, 503, 504 и с 520 по 526. 0 использует прежние 60 секунд. Отрицательное значение выключает этот вид охлаждения. Если есть положительный Retry-After, используется эта подсказка. |

## 5. Типичные ошибки и границы

Значение 0 для секунд временного охлаждения не выключает охлаждение и не отклоняется. Остаётся 60 секунд. Только отрицательное значение выключает этот вид охлаждения. `disable-cooling: false` — действительное значение, им нельзя обозначить «пропуск».
