# Прокси ключа

## 1. Какую задачу решает этот раздел

Позволяет одной группе upstream или одному ключу использовать собственный прокси вместо глобального.

## 2. Когда применимо и чего здесь нет

Прокси провайдера, совместимого с OpenAI, находится в записи keys. См. api-key-entries рядом со страницей веса. Эта страница — proxy-url других провайдеров.

## 3. Как настроить или вызвать

```yaml
api-keys:
  gemini:
    - name: gemini-1
      proxy-url: "https://example.invalid"
      keys:
        - api-key: "YOUR_API_KEY"
          proxy-url: "https://example.invalid"
```

Шаблон v8 также позволяет пустому значению откатиться к глобальному `requests.proxy-url`, а `direct` означает прямое соединение.

## 5. Типичные ошибки и границы

У этих ключей на этой странице нет отдельного отказа по синтаксису URL. Пустая строка считается откатом.
