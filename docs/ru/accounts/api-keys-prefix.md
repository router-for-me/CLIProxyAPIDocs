# Префикс имени модели

## 1. Какую задачу решает этот раздел

Добавляет префикс имени модели к одним учётным данным или одному провайдеру, чтобы одноимённые модели разных групп не смешивались.

## 2. Когда применимо и чего здесь нет

Префикс записывается на группе, и один ключ может его перекрыть. Это не псевдоним OAuth.

## 3. Как настроить или вызвать

```yaml
api-keys:
  gemini:
    - name: gemini-1
      prefix: "teamA"
      keys:
        - api-key: "YOUR_API_KEY"
```

При вызове используется `teamA/` плюс имя модели, и только тогда выбирается эта группа.

## 5. Типичные ошибки и границы

Пустая строка означает, что префикс не требуется. При загрузке не проверяется, содержит ли префикс косую черту.
