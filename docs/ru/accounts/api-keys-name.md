# Имя провайдера, совместимого с OpenAI

## 1. Какую задачу решает этот раздел

Даёт одному upstream, совместимому с OpenAI, устойчивое имя для распознавания и для мест вроде User-Agent.

## 2. Когда применимо и чего здесь нет

`name` в группах v8 других провайдеров — только метка группы. Это не возможность этой страницы.

## 3. Как настроить или вызвать

```yaml
api-keys:
  openai-compatibility:
    - name: openrouter
      base-url: "https://example.invalid"
      keys:
        - api-key: "YOUR_API_KEY"
```

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| api-keys.openai-compatibility.name | Имя, по которому узнают провайдера, совместимого с OpenAI. | empty string | Нужно, чтобы узнать этот провайдер. Шаблон говорит, что оно появляется в местах вроде User-Agent. |

## 5. Типичные ошибки и границы

У пустого имени нет отдельного сообщения об отказе. Запись без base-url удаляется при упорядочивании.
