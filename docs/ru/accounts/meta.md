# Вход Meta

## 1. Какую задачу решает этот раздел

Здесь описан вход Meta Muse по коду устройства.

## 2. Когда применимо и чего здесь нет

Ключи API находятся на страницах ключей upstream. Внутренний обмен токенами Muse здесь не описывается.

## 3. Как настроить или вызвать

```bash
cli-proxy-api --meta-login
cli-proxy-api --meta-login --no-browser
```

Команда печатает адрес проверки и код пользователя. Без `--no-browser` она открывает браузер и ждёт, пока Meta не сообщит об истечении или о завершении авторизации. `--oauth-callback-port` этим процессом не используется.

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| Meta login | Команда, которая запускает этот вход или импорт. |  | Запускается через --meta-login. |
| --meta-login | Команда, которая запускает этот вход или импорт. | false | Код устройства Meta Muse. Параметр порта обратного вызова не используется. |

## 5. Типичные ошибки и границы

Если нет device code или user code, процесс не удаётся. Когда код устройства истекает, ошибка содержит `device code has expired`. Если авторизация отклонена, процесс не удаётся.
