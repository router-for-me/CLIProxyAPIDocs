# Исключённые модели ключа

## 1. Какую задачу решает этот раздел

Не даёт одной группе upstream или одному ключу предлагать перечисленные модели.

## 2. Когда применимо и чего здесь нет

Это исключение на учётных данных ключа API. Файловые учётные данные OAuth используют oauth.excluded-models. У провайдера, совместимого с OpenAI, отдельного поля исключения нет.

## 3. Как настроить или вызвать

```yaml
api-keys:
  gemini:
    - name: gemini-1
      excluded-models:
        - "gemini-2.5-pro"
        - "gemini-2.5-*"
        - "*-preview"
        - "*flash*"
      keys:
        - api-key: "YOUR_API_KEY"
          excluded-models: []
```

Пустой список на ключе очищает исключения, унаследованные от группы.

## 5. Типичные ошибки и границы

Шаблон, который ничему не соответствует, просто ничего не исключает. Загрузка конфигурации из-за этого не падает.
