# Вход Devin

## 1. Какую задачу решает этот раздел

Здесь описано, как войти в Devin / Cognition и сохранить учётные данные сеанса.

## 2. Когда применимо и чего здесь нет

Чувствительные слова находятся в настройках провайдера на странице OAuth, а не здесь. `/callback` на основной службе тоже вынесен на отдельную страницу.

## 3. Как настроить или вызвать

```bash
cli-proxy-api --devin-login
cli-proxy-api --devin-login --no-browser
```

Без `--no-browser` по умолчанию привязывается временный порт. Если `--oauth-callback-port` больше 0, используется этот порт. Адрес обратного вызова имеет вид `http://127.0.0.1:<port>/callback`, ожидание — 5 минут. `--no-browser` не запускает порт обратного вызова, а просит вставить код авторизации или токен сеанса в подсказке. Текст подсказки — `Paste the Devin authorization code or session token directly:`.

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| Devin login | Команда, которая запускает этот вход или импорт. |  | Запускается через --devin-login. Это может быть обратный вызов браузера или вставленный токен. |
| --devin-login | Команда, которая запускает этот вход или импорт. | false | По умолчанию временный порт. С --no-browser переходит на вставку кода авторизации или токена сеанса. Ожидание обратного вызова — 5 минут. |

## 5. Типичные ошибки и границы

Режим без браузера не удаётся, если нет интерактивной подсказки. Ошибка содержит `requires an interactive prompt`. Пустой ввод отменяет процесс. Несовпадение state приводит к ошибке. Ошибка содержит `state mismatch`. Неудачная запись обратного вызова описана на странице обратного вызова OAuth.

## 6. Связанные возможности

Чувствительные слова описаны в разделе [Каталог OAuth, псевдонимы и исключения](/ru/accounts/oauth). Обратный вызов основной службы — в разделе [Обратные вызовы OAuth](/ru/accounts/oauth-callback).
