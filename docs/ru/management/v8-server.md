# Последняя версия

## 1. Какую задачу решает этот раздел

Спросить у API управления метку последнего выпуска CLIProxyAPI на GitHub. Вложения выпуска не скачиваются.

## 2. Когда применимо и чего здесь нет

Нужен ключ управления. Это не обновляет процесс и не читает версию локального двоичного файла как «последнюю». Приоритет токена GitHub описан в разделе [Прослушивание и процесс](/ru/operations/server).

## 3. Как настроить или вызвать

```http
GET /v8/management/server/latest-version HTTP/1.1
Host: example.invalid
Authorization: Bearer YOUR_API_KEY
```

При успехе возвращается JSON. Поле `latest-version` — метка выпуска. Запрос уходит в интерфейс latest release на GitHub. Если настроен исходящий `proxy-url`, этот запрос идёт через этот прокси. Новый ключ прокси здесь не добавляется.

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| GET /v8/management/server/latest-version | Читает метку или имя последнего выпуска GitHub. |  | Сначала используется `tag_name`. Если оно пустое, используется `name`. Если оба пусты, ответ — 502 `invalid_response`. Upstream не 200, сетевой сбой или ошибка декодирования — 502. Если создать запрос не удалось, ответ — 500 `request_create_failed`. |

## 5. Типичные ошибки и границы

Тайм-аут запроса — 10 секунд. Если доступного токена GitHub нет, всё равно отправляется неаутентифицированный запрос. Он может упереться в ограничение частоты GitHub и получить 502 `unexpected_status`. В ответе нет описания выпуска и установочного пакета.

## 6. Связанные возможности

Источник токена описан в разделе [Прослушивание и процесс](/ru/operations/server). Ключ управления — в разделе [Параметры управления](/ru/operations/management-settings).
