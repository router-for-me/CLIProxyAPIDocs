# Management API

## 1. Какую задачу решает этот раздел

Здесь сказано, что `/v0/management` больше не сопровождается. Новые вызовы не должны считать этот набор интерфейсов актуальным.

## 2. Когда применимо и чего здесь нет

Эта страница не регистрирует старые маршруты и не даёт шагов вызова. Актуальный интерфейс управления — [Management API v8](/ru/management/apiv8). Ключ и переключатель удалённого доступа по-прежнему описаны в разделе [Параметры управления](/ru/operations/management-settings). Эти параметры по-прежнему действуют на сохранившееся поведение процесса, но не являются инструкцией по использованию v0.

## 3. Как настроить или вызвать

Актуального способа вызова нет. Используйте `/v8/management`, начиная с раздела [Management API v8](/ru/management/apiv8).

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| management.v0.deprecated | `/v0/management` больше не сопровождается и не описывается по маршрутам. |  | Страница-владелец сохраняет только замечание об устаревании. |

## 5. Типичные ошибки и границы

В режиме Home, или когда ключ управления, `MANAGEMENT_PASSWORD` и локальный пароль не заданы, этот префикс возвращает 404. Не записывайте ответ, который когда-то получил старый клиент, как действующий контракт.

## 6. Связанные возможности

Актуальные маршруты конфигурации и эксплуатации описаны в разделе [Management API v8](/ru/management/apiv8).

## 7. Практический опыт

Пока нет.
