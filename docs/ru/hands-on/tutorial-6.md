# Шесть: графический интерфейс для новичка

Подключитесь к уже существующему интерфейсу управления или терминальному интерфейсу ключом управления. Описание самого интерфейса остаётся на своей странице и здесь не переписывается.

## Сценарий

Прокси уже работает через [Запуск через Docker Compose](/ru/docker/docker) или локальный двоичный файл. Вы хотите открыть панель управления, настольный клиент или терминальный интерфейс.

## Шаги

1. Сначала добейтесь регистрации маршрутов управления: задайте ключ управления и решите, разрешён ли доступ не с локальной машины и отдаётся ли панель управления. Всё это в разделе [Параметры управления](/ru/operations/management-settings). Для ключа используйте `YOUR_API_KEY`.
2. Из какого репозитория скачивается панель и когда она обновляется, тоже смотрите только на той же странице. Действия на странице — в разделе [Web UI](/ru/management/webui). Не копируйте описания кнопок обратно сюда.
3. Установка настольного клиента и подключение учётных записей описаны в разделе [Настольный клиент](/ru/management/gui). Эта страница не повторяет его шаги OAuth или подключения API.
4. Если удобнее остаться в терминале, см. [Терминальный интерфейс](/ru/operations/tui). Адрес удалённого управления по-прежнему следует параметрам управления.
5. После подключения изменение конфигурации идёт через [Management API v8](/ru/management/apiv8), учётные данные — через [Учётные данные управления](/ru/management/v8-credentials), сеансы OAuth — через [OAuth управления](/ru/management/v8-oauth).
6. `/v0/management` больше не сопровождается. Не вызывайте его по старому учебнику. См. [Management API](/ru/management/api).

## Чего не следует завершать на этой странице

Не пишите здесь примеры запросов управления и не превращайте адрес репозитория панели в значение, особое для учебника.
