# Каталоги моделей

## 1. Какую задачу решает этот раздел

`models` задаёт источник общего каталога моделей, клиентского каталога Codex и каталога Devin. Три пункта не влияют друг на друга. Пустое значение оставляет умолчание процесса: `--local-model` использует встроенный каталог, иначе используется официальный удалённый каталог. Абсолютный путь или адрес http(s) перекрывает только соответствующий пункт и имеет приоритет над `--local-model`.

## 2. Когда применимо и чего здесь нет

Эти три пункта записываются в `models` файла конфигурации. Здесь не объясняется маршрутизация конкретного ID модели и внутренние поля JSON каталога.

Режим Home отключает общий каталог и каталог Devin, даже если для них указан явный источник. Каталог Codex режим Home не отключает. В `config.example.yaml` сказано только, что режим Home не загружает общий каталог; это расходится с кодом. Верен код.

Если обновление явного источника не удалось, сохраняется предыдущий действительный каталог. Возврата к официальному адресу нет. Файл и URL обновляются при смене источника, затем каждые 3 часа. Встроенный источник загружается один раз и повторно с этим интервалом не запрашивается.

## 3. Как настроить или вызвать

Пустые значения в примере конфигурации — это форма по умолчанию:

```yaml
models:
  catalog: ""
  codex-catalog: ""
  devin-catalog: ""
```

Чтобы заменить один пункт, укажите абсолютный путь или адрес http(s) с именем хоста. Путь и адрес ниже — заполнители, а не значения по умолчанию:

```yaml
models:
  catalog: "/absolute/path/models.json"
  codex-catalog: "https://example.invalid/codex.json"
  devin-catalog: ""
```

Чтобы только пустые пункты использовали встроенный каталог, добавьте к запуску `--local-model`. Уже записанные пункты по-прежнему используют явный источник выше.

```bash
CLIProxyAPI --local-model --config /path/to/config.yaml
```

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| models.catalog.value | `models.catalog`, источник общего каталога моделей. | empty string | Пустое значение при `--local-model` — встроенный каталог, иначе официальный удалённый каталог. Непустое значение должно быть абсолютным путём или URL http(s) с именем хоста. Режим Home отключает пункт и больше не читает явный источник. |
| models.codex-catalog.value | `models.codex-catalog`, источник клиентского каталога моделей Codex. | empty string | Пустой и явный источник следуют тем же правилам. Режим Home этот пункт не отключает. |
| models.devin-catalog.value | `models.devin-catalog`, источник каталога моделей Devin. | empty string | Пустой и явный источник следуют тем же правилам. Режим Home отключает пункт, даже если явный источник записан. Комментарий в примере этого не говорит. |

## 5. Типичные ошибки и границы

Относительный путь, неразбираемый адрес, схема не http и не https, а также адрес http(s) без имени хоста отклоняются при загрузке конфигурации. Текст ошибки: `models.<field> must be an http(s) URL or an absolute local path`. `<field>` — это `catalog`, `codex-catalog` или `devin-catalog`. Конфигурация при этом не загружается.

Если пользовательский источник вернул неуспешный HTTP-статус, файл не открывается, содержимое недействительно или чтение превысило предел размера, это обновление не удаётся и сохраняется предыдущий действительный каталог. Пользовательский источник не переключается на официальный адрес. Источник, помеченный как отключённый, не читается.
