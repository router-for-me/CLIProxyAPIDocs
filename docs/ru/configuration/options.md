# Указатель

Подробности конфигурации, которые раньше были собраны на этой странице, разделены по задаче поиска. Эта страница больше не регистрирует возможности и больше не повторяет значения по умолчанию или конечные точки каждого ключа.

- Прослушивание, TLS, обнаружение, проверка работоспособности, журналы, конечная точка управления, терминальный интерфейс, Home и загрузка плагинов: см. страницы эксплуатации и управления. Входы — [Прослушивание и процесс](/ru/operations/server) и [Management API v8](/ru/management/apiv8).
- Вызовы клиента описаны в разделе [Клиентские ключи](/ru/api/access).
- Учётные записи, upstream и хранилище — на страницах учётных записей и upstream, а также в разделе [Директория аутентификации](/ru/configuration/auth-dir).
- Маршрутизация и запросы — в разделе [Стратегия маршрутизации](/ru/routing/strategy).
- Мышление моделей — в разделе [Мышление моделей](/ru/configuration/thinking-models).
- `/v0/management` больше не сопровождается. См. [Management API](/ru/management/api).
