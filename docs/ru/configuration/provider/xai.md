# Инструмент поиска xAI

## 1. Какую задачу решает этот раздел

Если запрос не объявил x_search, прокси добавляет нативный инструмент поиска xAI.

## 2. Когда применимо и чего здесь нет

Вход и ключи API на этой странице не описаны. После внедрения, когда это применимо, он также добавляется в tool_choice.allowed_tools.

## 3. Как настроить или вызвать

```yaml
upstream:
  xai:
    inject-x-search: false
```

## 4. Подробности

Столбец «По умолчанию» совпадает с `defaults` в реестре дословно.

| Поле | Значение | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| upstream.xai.inject-x-search | Внедрять ли x_search xAI, если запрос его не объявил. | false | При true внедряется только если запрос не объявил x_search, и когда это применимо, также добавляется в tool_choice.allowed_tools. |

## 5. Типичные ошибки и границы

false или пропуск ничего не внедряют. true внедряет только когда сам запрос не объявил этот инструмент.

## 6. Связанные возможности

Вход описан в разделе [Вход xAI](/ru/accounts/xai).
