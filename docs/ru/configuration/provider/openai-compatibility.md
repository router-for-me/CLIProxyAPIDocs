# Указатель

Провайдер, совместимый с OpenAI, теперь записывается в `api-keys.openai-compatibility`. Имя, отключение, ключи и модели описаны в разделах [Имя провайдера, совместимого с OpenAI](/ru/accounts/api-keys-name), [Отключение провайдера, совместимого с OpenAI](/ru/accounts/api-keys-disabled), [Ключи upstream API](/ru/accounts/api-keys-api) и [Псевдонимы моделей upstream](/ru/accounts/api-keys-models). Эта страница больше не регистрирует возможности.
